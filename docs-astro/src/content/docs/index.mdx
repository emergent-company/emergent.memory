## SDKs

<CardGrid>
  <Card title="Go SDK" icon="lucide:puzzle">
    A fully type-safe client library covering the complete Memory API surface —
    30 service clients, dual authentication, multi-tenancy, streaming SSE, and
    structured error handling.

    `github.com/emergent-company/emergent.memory/apps/server/pkg/sdk`

    <LinkButton href="/emergent.memory/go-sdk/" variant="secondary" icon="right-arrow">Get started with the Go SDK</LinkButton>
  </Card>
  <Card title="Python SDK" icon="lucide:puzzle">
    A full-featured client library for the Memory API — 14 sub-clients, three
    auth modes, SSE streaming, and structured error handling.

    Package `emergent-memory` (not yet on PyPI — install from source)

    <LinkButton href="/emergent.memory/python-sdk/" variant="secondary" icon="right-arrow">Python SDK reference</LinkButton>
  </Card>
  <Card title="Swift SDK" icon="lucide:puzzle">
    The Swift surface is the `EmergentKit` package under `swift/EmergentKit`,
    used by the iOS and Mac apps in this repository. It is not yet published as
    a standalone Swift Package, so it has no reference documentation here.

    <LinkButton href="https://github.com/emergent-company/emergent.memory/tree/main/swift/EmergentKit" variant="secondary" icon="external">View EmergentKit source</LinkButton>
  </Card>
</CardGrid>
