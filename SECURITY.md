# Security Policy

## Reporting a Vulnerability

Report security vulnerabilities privately via a GitHub Security Advisory:

https://github.com/emergent-company/emergent.memory/security/advisories/new

Do not open a public issue for a suspected vulnerability. Maintainers triage
advisory reports privately and will acknowledge receipt within a few business
days.

## Scope

This policy covers the code in this repository: the server, CLI, connectors,
web UI, SDKs, and their supporting configuration. It does not cover
third-party components, which are attributed in [NOTICE](NOTICE) and maintained
upstream.

## Supported Versions

Only the latest release is supported for security fixes. Vulnerabilities are
triaged against the latest release and fixed in a subsequent release; older
releases and unreleased branches do not receive security patches.
