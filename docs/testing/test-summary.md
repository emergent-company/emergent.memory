Current inventory of test suites, grouped by app, with the test environments each uses.
Generated from live recon of the Go monorepo (September 2026).

## Server — `apps/server/` (Go)

| Kind | Location | Count | Env |
|---|---|---|---|
| Unit | `domain/**`, `pkg/**`, `internal/**` `*_test.go` | ~243 files | in-memory / httptest, no DB |
| DB unit | `*_db_test.go` (graph, schemas) | 6 files | real Postgres; skip unless `TEST_DATABASE_URL`/`POSTGRES_HOST` set |
| Integration | `tests/integration/` | 18 files | real Postgres + LLM creds (`DEEPSEEK_API_KEY`, `GOOGLE_API_KEY`); skip without key |
| Sandbox e2e | `domain/sandbox/*e2e*_test.go` | 2 files | Docker daemon |

**Test DB**: template `go_test_template` built from embedded `internal/testutil/schema.sql`
(pg_dump; `kb` + `core` schemas, `pgcrypto`/`uuid-ossp`/`vector` extensions). Per-test DB via
`CREATE DATABASE ... TEMPLATE`, dropped on close. No Goose migrations in Go tests.
Helpers: `internal/testutil/` (BaseSuite, in-process Echo with ~30 routes, auth fixtures).
SDK mock: `pkg/sdk/testutil/mock.go`.

**Envs**: `POSTGRES_HOST`/`POSTGRES_PORT` (dev 5432), `TEST_DATABASE_URL` (full DSN),
`TEST_SERVER_URL` (external-server mode), `TEST_API_TOKEN`/`TEST_PROJECT_ID` (external e2e),
`LLM_ENCRYPTION_KEY`. Loaded from `.env` / `.env.local`.

**Run**: `task test` (= `go test ./...`, includes integration) · `task test:integration` · `task test:coverage`.

## CI — `.github/workflows/` (18 files)

Per-app path-filtered workflows. **No CI job uses services/Postgres/Zitadel** — integration,
e2e, and connector e2e run **local-only**.

| Workflow | Tests run |
|---|---|
| `server.yml` | golangci lint, `go build`, `go test -short ./internal ./pkg ./domain` (unit only), docker, migration-guard |
| `cli.yml` | golangci lint, `go test -v -race ./...` + codecov |
| `web-ui.yml` | templ generate → css → build → vet → `go test ./...` → golangci |
| `server-sdk.yml` | lint, `go test -v -race ./...` |
| `python-sdk.yml` | ruff, mypy, pytest matrix |

Required status check: `ci` (Meta CI, non-path-filtered). Release fan-out from
`auto-tag.yml` `v*` → connector/mac/ios/cli/image publishes.
